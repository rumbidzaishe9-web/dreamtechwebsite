# Dream Tech Website

A responsive multi-page website starter based on your design references and master prompt.

- `index.html` — homepage, introduction, two services, why choose us, process, FAQ, final CTA
- `services.html` — overview of the two services

## Supporting files
- `styles.css` — shared visual design and responsive styles
- `script.js` — central WhatsApp number, prefilled messages, mobile menu, current year, intro animation
- `robots.txt` and `sitemap.xml` — initial technical SEO files
- `favicon.svg` — simple monochrome favicon

## Run locally
1. Extract this ZIP.
2. Open the folder in Visual Studio Code.
3. Open `index.html` in your browser, or use VS Code Live Server.

The website uses no build system or JavaScript framework. Google Fonts and sample photography load from external URLs and need an internet connection.
